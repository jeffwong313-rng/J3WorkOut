Muscle Database

The backend sheet behind every suggestion: which muscles each exercise works. Primary = main mover (100%), Secondary = assists (50%), Tertiary = stabilizes (25%). When you mark something sore, exercises that use it as primary or secondary are avoided; marked "rest/injured", anything that touches it is avoided. Tap ✎ to edit a row (great for exercises you add yourself) or export the sheet to Excel / Google Sheets.

Workout Days

Name your split days (Push, Pull, Legs, or anything you like) and pick which exercises fall under each one. The Workout Plan progress bar always matches whatever you set here.
